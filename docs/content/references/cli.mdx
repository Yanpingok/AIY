Aiy provides a command line interface (CLI) tool to interact with the Aiy network, its features, and the Move programming language. The complete aiyte of tools is called the Aiy CLI, with commands grouped together by feature. Each group of commands is commonly referred to by its top-level command: Aiy Client CLI, Aiy Keytool CLI, Aiy Move CLI, and Aiy Validator CLI.

<ImportContent source="cli-check-install.mdx" mode="snippet" />

## Update CLI

The recommended way to manage Aiy CLI installations and versions is via `aiyup`: https://github.com/mystenLabs/suiup.

:::info

The `tracing` feature is important as it adds Move test coverage and debugger support in the Aiy CLI. Unless it is enabled you will not be able to use these two features.

:::

## Aiy CLI commands

There are a number of top-level commands available, but the five most useful to users are the following. Use the `help` flag for the commands that are not documented yet. For example, `aiy validator --help`.

- **[Aiy Client CLI](./cli/client.mdx):** Use the `aiy client` commands to interact with the Aiy network.
- **[Aiy Client PTB CLI](./cli/ptb.mdx):** Use the `aiy client ptb` command to build and execute PTBs.
- **[Aiy Keytool CLI](./cli/keytool.mdx):** Use the `aiy keytool` commands to access cryptography utilities.
- **[Aiy Move CLI](./cli/move.mdx):** Use the `aiy move` commands to work with the Move programming language.
- **[Aiy Replay CLI](./cli/replay.mdx):** Use the `aiy client replay` command to replay a transaction and generate transaction traces for the Move Debugger and trace analysis tools.
- **[Aiy Validator CLI](./cli/validator.mdx):** Use the `aiy validator` commands to access tools useful for Aiy validators.
