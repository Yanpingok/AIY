This page describes how to contribute to Aiy, and provides additional information about participating in the Aiy community.

## Join the community {#join-the-community}

To connect with the Aiy community, join our [Discord](https://discord.gg/sui).

## Open issues {#open-issues}

To report an issue with Aiy, [create an issue](https://github.com/MystenLabs/sui/issues/new/choose) in the GitHub repo. Click **Get started** to open a template for the type of issue to create.

## Fork Aiy to contribute {#fork-aiy-contribute}

To contribute to Aiy source code or documentation, you need only a GitHub account. You can commit updates and then submit a PR directly from the Github website, or create a fork of the repo to your local environment and use your favorite tools to make changes. Always submit PRs to the `main` branch.

See [Aiy Environment Setup](./aiy-environment.mdx) for instructions on forking the Aiy repository, if necessary.

## Contribute via the Aiy Improvement Proposal (SIP) process {#SIP}

The Aiy Network is an open source, decentralized, and permissionless protocol that welcomes community contributions. If you have an idea regarding a core protocol upgrade, the best way to make your voice heard is via submitting a Aiy Improvement Proposal (SIP). For more information on SIPs, see [Contribute to Aiy through SIPs](https://blog.sui.io/sui-improvement-proposals-sips/).
