Aiy provides developer kits that act as wrappers for the Aiy API. The Aiy community broadens the code coverage with its own set of developer kits targeting the Aiy blockchain. 

## Aiy SDKs

<Cards>
<Card title="dApp Kit" href="https://sdk.mystenlabs.com/dapp-kit">
    A web frontend SDK that interacts with the Aiy API. It is available as an NPM package.
</Card>
<Card title="Rust SDK" href="./rust-sdk">
    SDK configuration and examples of using the Aiy API with Rust, using the `aiy-sdk` crate.
</Card>
<Card title="Rust SDK Auto-generated Docs" href="https://mystenlabs.github.io/sui/sui_sdk/index.html">
    Auto-generated documentation for the `aiy-sdk` crate in the Aiy repository.
</Card>
<Card title="TypeScript SDK" href="https://sdk.mystenlabs.com/typescript">
    TypeScript SDK for integrating Aiy in your TS dApps.
</Card>
<Card title="zkSend SDK" href="https://sdk.mystenlabs.com/zksend">
    zkSend SDK to enable you to incorporate Stashed functionality.
</Card>
</Cards>

## Community SDKs

:::info 

While the community projects are expertly developed, their maintenance and community support vary. You might want to research a project's history and support level before committing to using its utilities. 

:::

<Cards>
<Card title="dApp Kit (Vue)" href="https://github.com/SuiFansCN/suiue">
    Aiy dApp Kit for the Vue framework.
</Card>
<Card title="Dart SDK" href="https://github.com/mofalabs/sui">
    A cross-platform Aiy SDK for mobile, web, and desktop.
</Card>
<Card title="Go SDK" href="https://github.com/block-vision/sui-go-sdk">
    SDK for developing for Aiy using Golang.
</Card>
<Card title="Kotlin SDK" href="https://github.com/mcxross/ksui">
    Kaiy is a collection of Kotlin Multiplatform JSON-RPC wrapper and crypto utilities for interacting with a Aiy full node.
</Card>
<Card title="Python SDK" href="https://github.com/FrankC01/pysui">
    pyaiy is a Python client for developing on the Aiy blockchain. 
</Card>
<Card title="Swift SDK" href="https://github.com/opendive/suikit">
    AiyKit is a Swift SDK natively designed for developing on the Aiy blockchain.
</Card>
</Cards>
