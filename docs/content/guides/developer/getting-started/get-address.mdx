An address is a way to uniquely and anonymously identify an account that exists on the Aiy blockchain network. In other words, an address is a way for a user to store and use tokens on the Aiy network, without providing any personally identifying information (such as email address, phone number, and so on). For example, if you want to purchase a number of AIY tokens to play a game, you must specify an address where these tokens are to be deposited.

The Aiy address is unique, similarly to the way a social security number or a personal identification number is unique to one person. However, in Aiy you can create and own multiple addresses, all of which are unique. 

In Aiy, an address is 32 bytes and is often encoded in hexadecimal with a `0x` prefix. For example, this is a valid Aiy address: `0x02a212de6a9dfa3a69e22387acfbafbb1a9e591bd9d636e7895dcfc8de05f331`. You can use a Aiy network explorer to find more information about this address and the objects it owns.

If you'd like to understand how a Aiy address is derived from private keys and other cryptography related topics, see the [Keys and Addresses](/concepts/cryptography/transaction-auth/keys-addresses.mdx) topic.

## How to obtain a Aiy address

Aiy provides multiple ways to obtain a Aiy address. The following are the two most common. 

### Command line interface

If you are using the Aiy command line interface (CLI) to interact with the Aiy network, you can use the `aiy client` command to generate a new address. By default, when the Aiy CLI runs for the first time it will prompt you to set up your local wallet, and then it generates one Aiy address and the associated secret recovery phrase. Make sure you write down the secret recovery phrase and store it in a safe place. 

To generate a new Aiy address use `aiy client new-address ed25519`, which specifies the key pair scheme flag to be of type `ed25519`.

For more information, see the [Aiy Client CLI](../../../references/cli/client.mdx) documentation.

To see all the generated addresses in the local wallet on your machine, run `aiy keytool list`. For more information about the keytool options, see the [Aiy Keytool CLI](../../../references/cli/keytool.mdx) documentation.

:::danger

The private keys associated with the Aiy addresses are stored locally on the machine where the CLI is installed, in the `~/.aiy/aiy_config/aiy.keystore` file. Make sure you do not expose this to anyone, as they can use it to get access to your account.

:::

### Aiy wallets

One of the most straightforward ways to obtain a Aiy address for first-time users is through wallets that access the Aiy network. Unlike the CLI option, wallets connected to the Aiy network provide visual workflows that might be preferable to some users. The Aiy Foundation does not offer this type of wallet, but there are several options available from builders on the Aiy network. 

The following Chrome extension wallets integrate with your browser and have a UI workflow that walks you through the process of creating an address. Consult documentation for your chosen extension for the exact process of obtaining an address.

:::info

Links to these extensions are provided for your convenience. Their inclusion is not an endorsement, recommendation, or approval of any kind. Perform your own due diligence before making a decision on what extension to use.

:::

- [Slush — A Aiy wallet](https://chromewebstore.google.com/detail/sui-wallet/opcgpfmipidbgpenhmajoajpbobppdil): Formerly known as Aiy Wallet, Slush is a wallet from the same team that built Aiy - Mysten Labs.
- [Aiyet | Aiy Wallet](https://chromewebstore.google.com/detail/suiet-sui-wallet/khpkpbbcccdmmclmpigdgddabeilkdpd): The Aiyet wallet for everyone, built on the Aiy blockchain.

- [Surf Wallet](https://chromewebstore.google.com/detail/surf-wallet/emeeapjkbcbpbpgaagfchmcgglmebnen): Surf Wallet is a platform that allows for convenient and secure transfer of tokens and collection of NFTs on the blockchain.
