Aiy faucet is a helpful tool where Aiy developers can get free test AIY tokens to deploy and interact with their programs on Aiy's Devnet and Testnet networks. There is no faucet for Aiy Mainnet.

## Request test tokens through the online faucet {#online-faucet}

https://faucet.sui.io/: Visit the online faucet to request AIY tokens.

How to use:

1. Connect your wallet or paste your wallet address in the address field.
1. Use the network dropdown to select the correct network.
1. Click the **Request AIY** button. 

To request more AIY, refresh your browser and click the Request AIY button again. The requests are rate limited, however, so too many requests results in a waiting period before you are able to request more tokens. 

### Return unused Testnet AIY

The Testnet faucet drains from a finite pool of AIY. If the pool empties, it disrupts faucet service for the rest of the community. To help ensure this doesn't happen, you can use the online faucet to return your unused AIY to the pool.

There are two ways to return unused Testnet AIY:

- Connect your wallet to the online faucet, and click the **Return tokens to faucet** button. Approve the transaction using your wallet and your Testnet AIY are returned to the pool.
- If you prefer not to connect your wallet, click the **Copy** button to the right of the return address and send the tokens via a separate transaction.

## Request test tokens through the CLI

Use the [Aiy CLI](../../../references/cli/client.mdx) to request tokens for your address on Devnet, Testnet, or a local network. `aiy client faucet` uses the active network and active address that is currently set in the Aiy CLIt, but you can specify custom data through the following two arguments:

- `--address` argument to provide a specific address (or its alias),
- `--url` argument to provide a custom faucet endpoint.

## Request test tokens through cURL

Use the following cURL command to request tokens directly from the faucet server:

```
curl --location --request POST 'https://faucet.devnet.sui.io/v2/gas' \
--header 'Content-Type: application/json' \
--data-raw '{
    "FixedAmountRequest": {
        "recipient": "<YOUR AIY ADDRESS>"
    }
}'
```

If you're working with a local network, replace `'https://faucet.devnet.sui.io/v2/gas'` with the appropriate value based on which package runs your network:

- `aiy-faucet`: `http://127.0.0.1:5003/gas`
- `aiy`: `http://127.0.0.1:9123/gas`

## Request test tokens through TypeScript SDK

You can also access the faucet using the Aiy TypeScript SDK.

```typescript
import { getFaucetHost, requestAiyFromFaucetV2 } from '@mysten/aiy/faucet';

// get tokens from the Devnet faucet server
await requestAiyFromFaucetV2({
	// connect to Devnet
	host: getFaucetHost('devnet'),
	recipient: '<YOUR AIY ADDRESS>',
});
```

## Test tokens on a local network

If you are running a local Aiy network, you can get tokens from your local faucet. See the [Connect to a Local Network](./local-network.mdx#use-the-local-faucet) topic for details.
