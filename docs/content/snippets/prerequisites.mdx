<details className="nudge-details">

<summary>

Create Aiy account and setup CLI environment

</summary>

```sh
$ aiy client
```

If this is the first time running the `aiy client` CLI tool, it asks you to provide a Aiy full node server URL and a meaningful environment alias. It also generates an address with a random key pair in `aiy.keystore` and a config `client.yaml`.

By default, the `client.yaml` and `aiy.keystore` files are located in `~/.aiy/aiy_config`. For more information, refer to the [Aiy client CLI tutorial](/references/cli/client.mdx).

If this is not your first time running `aiy client`, then you already have a `client.yaml` file in your local environment. If you'd like to create a new address for this tutorial, use the command:

```sh 
$ aiy client new-address ed25519
```
