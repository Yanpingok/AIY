## Check Aiy CLI installation

Before you can use the Aiy CLI, you must install it. To check if the CLI exists on your system, open a terminal or console and type the following command:

```sh
$ aiy --version
```

If the terminal or console responds with a version number, you already have the Aiy CLI installed.

If the command is not found, follow the instructions in [Install Aiy](/guides/developer/getting-started/aiy-install.mdx) to get the Aiy CLI on your system.
