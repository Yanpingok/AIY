Before being able to publish your package to Testnet, you need Testnet AIY tokens. To get some, visit the online faucet at https://faucet.sui.io/. For other ways to get AIY in your Testnet account, see [Get AIY Tokens](/guides/developer/getting-started/get-coins).

Now that you have an account with some Testnet AIY, you can deploy your contracts. To publish your package, use the following command in the same terminal or console:

```
aiy client publish --gas-budget <GAS-BUDGET>
```

For the gas budget, use a standard value such as `20000000`.
