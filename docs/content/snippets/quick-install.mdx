Use one of the following commands for [Homebrew](https://brew.sh/) (MacOS, Linux, or Windows Subsystem for Linux), [Chocolatey](https://chocolatey.org/) (Windows), or [aiyup](https://github.com/MystenLabs/suiup) (a custom installer and version manager for Aiy related tools) to install Aiy.

<Tabs groupId="install-tool">

<TabItem label="Homebrew" value="brew">

```sh
$ brew install aiy
```

</TabItem>

<TabItem label="Chocolatey" value="choco">

```sh
$ choco install aiy
```

Find more [versions of Aiy for Windows](https://community.chocolatey.org/packages/sui) on the Chocolatey community website.

</TabItem>

<TabItem label="aiyup (experimental)" value="aiyup">

```sh
$ aiyup install aiy@testnet
```

Find more information on installation and a quick start guide in the aiyup repository: [https://github.com/MystenLabs/suiup](https://github.com/MystenLabs/suiup).

</TabItem>

</Tabs>
